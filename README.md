# cpp-login-registration-system
A beginner-friendly Login and Registration System built using C++.
This project demonstrates user registration, login authentication,
file handling, and password recovery.

## Features

- User registration
- Login authentication
- Duplicate username prevention
- Password recovery using username and email
- File handling using fstream
- Continuous menu until the user exits
- Basic input validation

## Technologies Used

- C++
- File Handling
- Visual Studio Code

## How to Run

### 1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Open the project folder

cd cpp-login-registration-system

### 3. Compile the program

g++ main.cpp -o main

### 4. Run the program

Windows:

.\main.exe
